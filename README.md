# MyPortfolio

## 🇮🇹 Descrizione

**MyPortfolio** è un'applicazione full-stack progettata per la gestione delle operazioni finanziarie personali. Il progetto include:

- **Backend**: API RESTful sviluppata con ASP.NET Core. 
- **Database**: PostgreSQL per la persistenza dei dati.
- **Servizi aggiuntivi**:
  - **PgAdmin**: Interfaccia web per la gestione del database.
  - **Servizio Python**: Microservizio per l'elaborazione dei dati finanziari.

## 🇬🇧 Description

**MyPortfolio** is a full-stack application designed for managing personal financial operations. The project includes:

- **Backend**: RESTful API developed with ASP.NET Core.
- **Database**: PostgreSQL for data persistence.
- **Additional services**:
  - **PgAdmin**: Web interface for database management.
  - **Python Service**: Microservice for processing financial data.
